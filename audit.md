**New bugs found (live + bug-hunter agent, ranked):**

**P1**
- **LAB-FREEZE (B1):** Order Book / Fib Sweep / Sentiment Board freeze permanently after leave-and-revisit AND orphan an immortal interval per visit. Self-stop wired wrong: interval stored on the element (`el._obTimer`) but the detach check calls `stopOrderBookDemo(containerId)` with the STRING id (lt-orderbook.js:247-258, lt-fib.js:103-104, lt-sentiment.js:128-129) → resolves `getElementById` to null/the NEW mount, never the detached owner. Orphan's next tick then clears the new element's timer (freezes ~1.3-1.5s after remount). Repro: C3ch3 demo step → Next → Prev → book freezes at phase 0/1. Ichimoku/Liqlab/Patternlib have no timers (safe). Fix: stop by element — `if (!document.body.contains(el)) { clearInterval(el._obTimer); el._obTimer=null; return; }` in each tick.
- **SIM-Y-TICKS:** Practice Simulator chart y-axis pins min/max to raw data extent → unrounded boundary ticks: top label renders "3,253.08" (clipped "33,253.08") beside clean 26,000/28,000/… (verified live). Fix: round axis min/max to tick interval (cf. `_engNiceStep`) in lt-sim-ui.js.

**P2**
- **B2 deep-link clamp:** `_ltParseRoute` clamps `s<=3` (engine:4701) but demo+module-final chapters have 5 steps (0–4) and `_ltSyncURL` writes `s=4` (:4756) — copied quiz links reopen at Introduction. Fix: widen clamp; `_ltBootLesson` already clamps against `lastStepIdx` (:4727).
- **B3 unlock/click asymmetry:** sidebar shows started chapters as unlocked (`!prevDone && !isStarted`, :3608-3609) but `jumpToChapter` requires completion (:3321) → deep-linked/glossary-jumped chapters render unlocked yet clicks silently no-op. Fix: allow started chapters in jumpToChapter, or toast on rejection.
- **B4 v2 loader caches failure as success:** per-script `onerror` resolves false but aggregate resolves true and is cached in `_v2LoadState[n]` forever (engine:2078-2087) → one network blip = "couldn't be loaded" for every lesson in that course all session. Fix: on any failure `delete _v2LoadState[n]` before resolving.
- **B5 stale-mount guard misses course switches:** renderV2Lesson guard checks only chapter/step indices (:2154-2156); course switch to same indices mounts the old chapter closure. Fix: also compare `getActiveCourseNum()`.
- **B6 sim teardown leaks:** leaving mid-reveal never clears `_simRevealTimer` (repaints detached chart, then `_sim2Score` commits a round from the course view, sim-ui:950-956); `_sim2RenderSetup`/`_sim2RenderEquityChart` create per-render ResizeObservers never disconnected (sim-ui:763,484).
