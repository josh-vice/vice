## ⚠️ MUST-KNOW for anyone editing lessons next

1. **v2 karaoke captions render the TTS `timings.json` words, which OVERRIDE the beat's `say`
   text.** So editing a lesson's `say` without regenerating its audio leaves the OLD narration
   on screen *and* in the voice. After ANY `say` edit:
   `node tools/tts/extract.mjs` then `tools/tts/.venv/bin/python tools/tts/generate.py <lessonId>`
   (or `--force` for all — ~525 beats, run in background). **Then bump `audioVersion` in
   lt-engine.js** (currently `'2.0.0'`) — the clip + timings fetches are cache-busted by that token,
   not by the file `?v=`.
2. **Chart edits must go through the node harness**, never eyeball-only. It replicates the engine's
   10-lead/6-trail context expansion (`lt-engine.js` ~946-999) + `LTTa` ichimoku/RSI math. Build it
   from `lt-chartgen.js` + `lt-ta.js`; scan seeds against explicit geometric constraints. Gotchas:
   leg-final candles land exactly on `to`; `reject` wick follows the LEG direction; ~12% of candles
   get a freak long wick (re-verify after ANY seed/leg change); markPoint indexes shift +10 at
   runtime; volume `spikes` keys are DISPLAYED (post-expansion) indexes. A working copy lived in the
   session scratchpad — rebuild if gone.
3. **New chart-vocabulary moves (Course 4)** are in `lessons-v2/chart-vocabulary.js`, each with a
   two-pass displacement-safe cloud where relevant, and each mechanism-tested (39 assertions). If
   you touch them, re-run those assertions.
4. **Per-phase discipline** (non-negotiable): back up touched files to `Backup-<date>_<slug>/` →
   implement → `node --check` every JS → engine sweep (all 4 data files through
   `buildCandlestickOption`, 0 throws/0 clipped) → v2 sweep (`ensureV2LessonsLoaded(1..4)` → every
   CHART/CANDLE beat through `LTRenderer`, 0 unknown anchors) → live eyeball desktop + ≤400px → bump
   cache tokens → **STOP for owner review. NEVER run `vercel` / deploy.**
