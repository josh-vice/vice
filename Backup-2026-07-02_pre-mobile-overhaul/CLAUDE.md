## Workflow discipline (every change)

1. **Backup first**: copy files you'll touch to `Backup-<date>_<slug>/` at repo root.
2. Implement fully — no stubs.
3. **Verify**: `node --check` every JS you edit; 0 console errors; for engine charts run every def through `buildCandlestickOption` (0 throws); for v2 lessons run the render sweep (`ensureV2LessonsLoaded(1..4)` → every `LT_LESSONS[id].beats` CHART/CANDLE beat through `new LTRenderer(...)` → 0 throws / 0 unknown anchors); for labs, harness-test then mount in-app; eyeball desktop AND ≤400px mobile; nothing clipped.
4. **Cache-bust**: bump `?v=` for the file in `lt-index.html`; v2 lesson files bust via the token hardcoded in `ensureV2LessonsLoaded` (lt-engine.js); `learn/` regenerates at Vercel build.
5. **NEVER deploy or push to Vercel** (no `vercel` commands). The owner deploys manually after reviewing each phase.
