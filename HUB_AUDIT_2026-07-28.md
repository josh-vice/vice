**Date:** 2026-07-28 · **Auditor:** incoming-CEO-mode deep dive (code + live UI + break-testing)
**Scope:** `vice/hub/index.html` (102 ln) · `vice/hub.js` (4,038 ln) · `vice/hub.css` (1,173 ln) · `/api/vice-*` proxies
**Method:** full code read of the shell/registry/store/editor; hands-on UI pass over all 3 presets, palette, focus mode, edit mode, add-tray, settings, Chart section; deliberate break-testing (corrupted storage, garbage inputs, rapid switching, mobile viewport). ---

## 0. TL;DR — the verdict

Vice Hub is a **genuinely good product with an invisible ceiling**. The engine layer (widget registry, layout store with migrations, trash/restore, command palette, focus boards, linked symbols) is better engineering than most funded dashboard startups ship. Zero console errors survived every abuse test I threw at it. The ceiling is that its *power is hidden and its surfaces are inconsistent*: configuration lives in modals nobody will open, ~50 widgets are sold through a text-only list, two news widgets compete in the default layout, and the TradingView-embed half of the catalog visually clashes with the native half.

**Top 5 moves (in order):**
1. **On-widget quick controls** (timeframe pills, symbol chip) — kills the #1 daily friction in one stroke.
2. **Unified News** — one news widget, multi-source, filterable; retire the duplicate pair.
3. **Add-tray → visual widget gallery** (thumbnails, search, descriptions) — the catalog is the product; today it's a phone book.
4. **Dashboard editor v2** (inspector panel, live preview of settings, explicit edit affordances) — the foundation for the "element builder" ambition.
5. **Persistence safety net** (auto-export reminder / file backup / optional sync) — everything users build lives in one fragile localStorage key.

## 1. What the product is today (inventory)

### 1.1 Surfaces
- **Dashboard** (`#/`) — 24-col gridstack canvas, 3 preset layouts (DeFi / TradFi / Macro), unlimited user layouts (new/duplicate/rename/delete/export/import JSON).
- **Chart** (`#/chart`) — full-page native charting (vchart.js engine: candles, indicator suite, book heatmap) + screener below. Genuinely differentiated.
- **Focus mode** (`F`, bar button, palette, or any ticker click) — auto-composed per-symbol board (Advanced Chart, Symbol Info, native Vice Chart, Top Stories, Mini Chart, Funding, Candle Close) with pin-to-dashboard on every block. Excellent concept, under-marketed.
- **Command palette** (`⌘K`) — actions, layout switching, widget adds, `type a ticker → Focus / Link charts`. Power-user gold.
- **Top bar** — brand, live price chip (layout-aware), Dashboard/Chart nav, Focus, palette, layout select, Add widget, Edit, ⋮ menu.

### 1.2 Widget catalog (~54 types across 7 categories)
- **Charts (5):** Advanced Chart (TV), Mini Chart (TV), Ticker Tape (TV), Vice Chart Pro (native), Vice Chart (native).
- **Markets (~10):** Crypto/Stock/ETF/Forex Heatmaps (TV), Market Overview (TV), Funding APR Heatmap, Sector Performance, OI-Normalized CVD, Market Volume, Total Open Interest (all native).
- **Futures (~13, native):** 24h Volume, OI Snapshot, Funding Rate APR, 1m Avg Return by Hour/Day, Return Buckets, Open Interest, Volume, CVD Dollars, 3M Annualized Basis, Price, Liquidations, Cumulative Return by Session, Change Leaders.
- **Options (~9, native, Deribit):** Spot-Vol Correlation, ATM IV, 25Δ Skew, IV Term Structure (+Slope), DVOL, Top Volume Options, OI by Strike, OI by Expiry.
- **Screeners (2, TV):** Crypto, Stock.
- **News & data (3, TV):** Top Stories, Economic Calendar, Symbol Info.
- **Vice originals (12):** Watchlist, Top Movers, Crypto News (aggregated RSS via proxy), Notes, Session Clocks, Price Alerts, Funding, Candle Close, Liquidity Map, Vice Heatmap, Screener, Vice Suite links.

### 1.3 Architecture notes worth protecting
- Registry pattern: one manifest per widget (`title/icon/cat/size/settings/mount/link/label`) — adding a widget is ~30 lines. This is the moat for an element-builder future.
- Layout store: versioned schema, **in-place migrations** on load (symbol renames, stale-preset patches, tape-height repair) — real product maturity.
- `trash` per layout + "Recently removed" restore in the add tray.
- Settings modal sanitizes (blank→default, numbers clamped).
- IntersectionObserver defers widget mount until near-viewport (+250px margin).
- Toasts support an action button (undo pattern present).
- Debounced persist (250ms) with quota-failure tolerance.

## 3. What doesn't work (ranked)

### 3.1 CRITICAL — product-level

**C1. Configuration is buried; daily controls don't exist on widget faces.**
Case study (owner-reported): Mini Chart appears locked to "1 month". The Range setting (1D/1M/3M/1Y/5Y/ALL) *exists* — behind hover → tiny gear → modal → dropdown → Save → full remount. Five steps for a one-click daily action, and the capability is invisible until discovered.
**Doctrine for the fix:** *settings modal = identity/configuration (rare); widget face = controls (daily).* Timeframe, symbol, interval, market belong on the face.
**Spec (P0):** a `controls` field in the widget manifest rendering a right-aligned micro-pill row in `hw-head` (or a footer strip on hover): Mini Chart `1D·1M·3M·1Y·ALL`; Advanced/Vice Charts `interval pills`; Heatmaps `24h·1W·1M`; News `source tabs`. Persist straight into `inst.settings` (no modal, no remount when the embed supports live option change; remount otherwise).

**C2. The catalog is invisible.** ~54 widgets sold via a text list with icon + name + "TradingView/Vice original · 12×9". No previews, no search, no descriptions, no "what is Return Buckets?". Users will add the 6 they understand and never meet the other 48. The tray is the store-front of the whole product.
**Spec (P0/P1):** search box + category chips; live-rendered thumbnail (or static PNG snapshot) per widget; one-line description in each manifest (`desc:`); a "Featured/New" row; hover = larger preview.

**C3. News is fragmented (owner-reported, confirmed).** `tvNews` (Top Stories, TV timeline) and `vNews` (aggregated RSS) ship side-by-side in the DeFi preset; Symbol Info also overlaps content-wise. Two headers, two scroll behaviors, two type systems.
**Spec (P1): one "News" widget** — native renderer, source tabs/filter chips (`All · TradingView · RSS (CoinDesk/The Block/Decrypt…) · Symbol`), symbol-aware when linked, relative timestamps, read-state dimming, compact/comfortable density toggle. Retire both old types via a store migration (auto-replace instances with the unified widget, mapping settings).

**C4. Persistence is a single point of loss.** Layouts, notes, alerts, watchlist = one localStorage key. Cleared site data, another browser, a corrupted write = everything gone (my corruption test wiped the store irrecoverably — by design). Export exists but is manual and buried in ⋮.
**Spec (P1):** periodic auto-download opt-in or File System Access API backup; "last backup: n days ago" nudge in ⋮; roadmap: tiny optional sync backend (even gist-style paste-a-code restore). This is also the account-system on-ramp if the Suite ever wants one.

### 3.2 MAJOR — experience level

**M1. Two visual languages.** TV iframes bring their own fonts, rounded avatars, TV watermarks, blue links; native widgets are mono/terminal. The TradFi preset is ~100% iframes — on that layout the product looks like "iframes in boxes" and the Vice identity disappears. Mitigations: (a) prefer native equivalents where they exist (heatmap: native Vice Heatmap could take default slots), (b) normalize chrome (consistent 1px borders, unified corner radius, mono headers — done), (c) long-term: replace highest-traffic TV widgets with native versions (screener and news first — screener already exists natively!).

**M2. TradFi persona gets a thin product.** All differentiated (native) widgets are crypto-only; TradFi/Macro presets contain zero Vice originals beyond Notes/Clocks. Either invest (stocks screener/news native, earnings calendar widget) or explicitly position the Hub as crypto-first with TradFi as garnish. Decide; don't drift.

**M3. Edit-mode ambiguity.** `staticGrid:false` means drag (by header) and resize are live *always*, not just in Edit. Accidental layout shuffles while trying to click a header are inevitable (especially with a trackpad). Meanwhile Edit mode's actual differences (persistent header buttons, Add button) are subtle; there are no grid guides, no drop shadows during drag, no "drag me" affordance for first-timers.
**Spec:** lock geometry outside Edit (or add a ⋮ preference "lock layout"); in Edit: dashed grid overlay, item lift-shadow while dragging, corner resize glyphs, and an esc/checkmark exit hint.

**M4. Widget-header information scent is weak.** Long titles truncate badly at preset sizes ("Candle Close" → "Can…", "Economic …", "Market Ov…", "Liquidity M…"). Title + context (symbol/market) + status (stale? refreshing? error) all compete inside ~150px. Spec: title auto-hides before context does (context matters more: "· SOLUSD" beats "Mini Chart"), tooltip with full title, a subtle staleness dot when a feed's last refresh > 2× its cadence.

**M5. Silent failures.** Garbage alert input (`abc!!`) is swallowed with zero feedback (row simply doesn't appear). API-down states vary per widget: some show a nice `note()` (vNews's CORS explainer is model behavior), some go blank forever. Spec: standard error/empty/loading skeleton states in the shell, not per-widget goodwill; invalid input shakes + hint.

**M6. Mobile is functional, not designed.** 2-col reflow works; the bar wraps awkwardly; palette/search affordance disappears entirely on ≤560px; drag on touch fights scrolling. Given "second monitor" positioning this is acceptable — but add: a mobile search/focus button, and consider a read-only "glance" mode (no drag) on touch.

### 3.3 MINOR — polish list (fast fixes)
- Session Clocks preset height clips the second row of clocks (Macro preset: h too small by ~2 rows).
- Funding table clips its last column at default width ("DERIBIT" → "DERIE").
- Candle Close crams "HH:MM:SS EDT · your time" under the title; the "5d" row gets cut at preset height.
- Forex Heatmap default width cuts the last currency column.
- Price Alerts placeholder shows prefilled-looking "700" (it's placeholder styling — reads as a value).
- Top Stories / Advanced Chart iframes flash white-ish on slow loads against the dark theme (give iframe containers the dark bg while loading — partially done, verify).
- Palette hint shows `⌘K` even on Windows (`Ctrl K` detection).
- The ⋮ menu mixes destructive (Delete layout) with navigation links (Suite/Tickers/Charts) — separate or move links to footer only.
- `hub-empty` state exists and is good — but reachable only by deleting everything; new-layout flow could start from it with template choices (see §5).

## 5. The big idea: from "dashboard" to "dashboard editor"
(owner's instinct: *"element builder… a more in-depth dashboard editor… make it clear you can design the dashboard to fit your needs"* — correct instinct; here's the staged path)

**Tier 1 — Make the existing editor legible (days).**
- Explicit Edit affordances (grid overlay, lift shadows, resize glyphs, locked-outside-edit).
- Visual add-gallery (C2 spec) with search + descriptions + thumbnails.
- On-widget quick controls (C1 spec).
- Rename "Edit" → "Customize" in the bar; first-visit coach-mark: "This whole page is yours — drag, resize, add."

**Tier 2 — Inspector-style editor (1–2 weeks).**
Select any widget in Customize mode → right-side inspector panel (not a modal): all settings live-apply with instant preview, size presets (S/M/L), duplicate button, "convert to…" for same-data widgets (Mini Chart ⇄ Advanced Chart ⇄ Vice Chart; tvNews ⇄ unified News). The modal dies. This *is* the "in-depth dashboard editor" and it's mostly UI over the existing manifest/settings plumbing.

**Tier 3 — Element Builder (the bet, 3–6 weeks).**
The registry already separates *data* from *presentation* internally (Coinalyze/OKX/Deribit fetchers → ECharts configs). Formalize it: user picks **data source** (symbol + metric: price/OI/funding/CVD/IV/…) × **visualization** (line/area/bars/heatmap-row/stat-tile/table) × **options** (timeframe, exchange, smoothing) → a custom widget saved into *their* palette, exportable as JSON, shareable as a code. Start with the Coinalyze metric family only (one API, ~10 metrics — cheapest slice that proves it). This turns the Hub from "our 54 widgets" into "your widgets" — the real moat, and the thing no TradingView-embed collection can copy.

**Sequencing rationale:** each tier ships value alone; Tier 3 reuses Tier 2's inspector as its editor shell. Do not start Tier 3 before Tier 1 lands — the current discoverability would bury it.

## 6. End-user journey findings

- **First visit:** you land on a good-looking DeFi board. Nothing says it's editable. The pencil is one of five bar glyphs. **Fix:** first-run coach-mark + "Customize" naming (Tier 1).
- **Daily driver (the "second monitor" persona — the core user):** wants: glance density, timeframe flips, one news column, alerts that fire. Friction today: timeframe modals (C1), duplicate news (C3), alerts have no history/management view beyond the widget body, no staleness indicators after sleep/wake (laptop lid reopen: are these numbers live? add per-widget last-updated dot, and a global "reconnected — refreshed n widgets" toast on wake).
- **Ticker-curious ("what's SOL doing?"):** Focus mode nails this — but it's invisible. Any ticker row click DOES focus (good), yet nothing teaches it. Fix: hover hint on first watchlist row ("click to focus"), and put "Focus" in the empty-state copy.
- **TradFi visitor:** thin product (M2). Decide the persona strategy before spending here.
- **Returning after a month:** layouts intact (localStorage) *if* same browser. Otherwise gone (C4). No "what's new" surface for the fast-moving widget catalog — a tiny changelog entry point in ⋮ would compound interest.

## 7. Performance & tech-debt notes
- Widget mount is lazy (IntersectionObserver) but **never unmounts** off-screen widgets; big layouts accumulate ~8 live iframes + N canvases + per-widget `setInterval`s (news 5m, funding etc.). Add unmount-on-far-exit (keep state in `inst.settings`), and pause timers on `document.hidden`.
- Every TV embed is a full third-party iframe (network + memory + their branding). Budget: default presets should hold ≤4 iframes; prefer native where equivalents exist.
- `hub.js` is 4,038 lines in one IIFE. Fine for now; the moment Tier 2/3 starts, split: `registry/`, `store.js`, `editor.js`, `palette.js`, `focus.js`. Do it *with* the editor work, not before (no behavior-only refactors).
- The dev server (`tools/vice-dev-server.py`) mirrors three proxies; keep parity tests trivial by extracting shared metric lists if the element builder lands.
- `document.title` tick updater: fix alongside B1 (single "title feed" owner tied to focus/layout state).
